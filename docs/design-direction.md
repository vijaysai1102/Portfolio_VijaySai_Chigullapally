# Studio direction

Canvas #f5f3ee; text #20221f; secondary #62665d; accent #456436; rule #d9dcd2; demo #191d19 with #f2f5ea text. Olive accents signal active controls; underline, borders and labels also communicate state. Native system sans keeps the site independent of external font availability; Georgia italic supplies editorial contrast. Type scale 12/14/16/20/32/56/88; fluid hero size; 1180px content width; 24px gutters; spacing 8/16/24/40/64/96.

Centered small brand/navigation, generous opening composition, oversized introduction left and an original orbital engineering diagram right. The centerpiece connects interface, system and evidence around a neutral VS monogram. It is a graphic, not a substitute photograph. A future portrait can replace the center without shifting its reserved dimensions. Thin rules organize long content. Work uses a large dark flagship and two balanced secondary project surfaces. No decorative metric claims.

Hover: links underline, project arrows translate 3px, cards gain border contrast. Focus: 3px olive outline with offset. Pointer: no pointer tracking or cursor replacement. Scroll: native scrolling, anchor offset; no hijacking or essential reveal animations. Touch: all labels visible and 44px minimum action targets. Motion: short opacity/transform transitions; reduced-motion disables transitions and smooth scrolling. Dark demo has native buttons, distinct selected state and visible sample-data label. Chat uses a bounded panel with visible close, dialog semantics, source links and explicit unavailable/error status.
