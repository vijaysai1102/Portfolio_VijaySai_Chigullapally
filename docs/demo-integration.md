URL state uses useSyncExternalStore with a stable server fallback to avoid hydration disagreement. Manual controls replace the fragment without scrolling or adding noisy history; explicit suggested links navigate normally and close chat. Same-page demo actions use native hash navigation so subscribers update. Reset returns overview and empty search. Search belongs to its view and clears when changing view. Structured chat context includes only a validated sample view for Megatron; the prompt labels its data fictional. No third-party host bridge is implied.

This does not prove an iframe or remotely controlled preview will work. Browser host unavailable, so responsive reuse feasibility remains unverified.

Under the approved plan's bounded-alternative scope, the portfolio contains a small independent illustrative explorer, not a rebuild or embed of Megatron. All data is fictional and labeled; it has no file access or plugin execution. Ordinary product/source links are the fallback. Local rendering means no third-party-frame loading/error state exists. A client loading failure leaves server-rendered copy and external links available.

Allowlisted views: overview, skills, usage. Search filters only the current sample collection; reset returns overview and empty search. Expansion uses native dialog focus containment, Escape handling and return focus. No postMessage bridge is implemented or trusted. T27 may control these local views through validated identifiers only; never assume remote host control. Sample labels and no-actual-billing wording remain visible.
