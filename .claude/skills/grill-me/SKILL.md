---
name: grill-me
description: Stress-test a portfolio plan or design through an interview when the user asks to be grilled or resolve design decisions.
---

Walk through the unresolved decisions in the user's plan, one question at a time. Recommend an answer and explain its tradeoff. Inspect the repository first when the code can answer a question.

For portfolio work, resolve audience and content before dependent layout, interaction, stack, and publishing decisions. Preserve decisions already settled by the user. The interview is read-only until the user authorizes implementation; follow the root guide's approval rule before editing multiple files or changing visible UI.
